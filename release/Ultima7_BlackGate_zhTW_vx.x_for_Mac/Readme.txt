# 創世紀 7 (Ultima 7) 中文化版 - macOS 安裝說明

你好!這是一個專為 macOS(Apple Silicon,M 系列晶片)打造的 Exult 中文化整合版。
這個 DMG 裡的 Exult.app 已經內含:中文化字型、翻譯文本、音樂與所有引擎資料。
你不需要自己編譯、不需要安裝 Homebrew、也不用手動複製任何資料夾——
只要把你擁有的正版遊戲檔案放進去,就能開始完美中文體驗!

## ⚠️ 準備工作(必讀)
本整合版為了符合版權規範,**不包含**原版遊戲的資源檔案。
請先準備好你購買的《創世紀 7》正版遊戲(例如從 GOG 平台下載並安裝好的版本)。

⚙️ 系統需求:
* macOS(Apple Silicon / M1、M2、M3… 系列)。本 App 為 arm64 版本。
* 約 300 MB 可用空間(不含遊戲本體)。

## 遊戲的取得
* 非常建議還沒有遊戲本體的人從 GOG 購買,因為 GOG 長期致力於支援舊遊戲,
  在該平台購買遊戲,是對開發者很好的支持~XD
* [GOG 平台](https://www.gog.com/zh/game/ultima_7_complete)

## 🛠️ 三步完成啟動!

### 第一步:安裝 Exult
把這個視窗裡的 **`Exult.app`** 拖曳到旁邊的 **「應用程式 (Applications)」** 捷徑上,完成安裝。

> 💡 第一次打開遇到「Apple 無法驗證…是否為惡意軟體」?
> 這是因為本 App 沒有付費簽章,並非病毒。解法二選一(只需做一次):
> * **作法 A(推薦)**:打開「終端機 (Terminal)」貼上以下指令後按 Enter:
>   `xattr -dr com.apple.quarantine /Applications/Exult.app`
> * **作法 B**:警告視窗按「完成」→ **系統設定 → 隱私權與安全性** → 往下捲到
>   「安全性」區,『已封鎖「Exult」』按 **「仍要打開」** → 輸入密碼 → 再按「打開」。
> * (較舊的 macOS 也可對 Exult.app 按住 Control 鍵點一下 → 「打開」;
>   macOS 15 之後已移除此捷徑)

### 第二步:第一次啟動,放入正版遊戲檔
雙擊 **`Exult.app`**。第一次啟動時,它會自動把中文化資料安置好,
然後跳出一個視窗,告訴你「還差正版遊戲檔」。這時:

1. 按 **「自動搜尋遊戲檔」**——如果你的 Mac 上已經裝了 GOG 版遊戲,
   它會自動找到並幫你複製,超省事!
2. 或按 **「打開 STATIC 資料夾」**,然後自己把原版遊戲(GOG 安裝資料夾裡
   那個 **`STATIC`** 資料夾)**內的所有檔案**複製進打開的資料夾中,
   再按「重新檢查」。

### 第三步:開始遊戲!
一切就緒!在選單選擇 **Ultima VII: The Black Gate** 即可進入遊戲,
中文文本與字型會自動掛載!

## 💾 關於遊戲存檔與資料位置
所有資料(中文化檔案、遊戲檔、存檔與進度)都集中在:

    ~/Library/Application Support/Exult/

黑門的存檔在 `Exult/blackgate/` 底下。想備份或換電腦,
把整個 `Exult` 資料夾打包帶走即可,進度原封不動跟著你!

> 註:macOS 版的設定檔 **`exult.cfg`** 位於 `~/Library/Preferences/exult.cfg`。
> 第一次啟動時會自動安裝一份調校好的預設設定(字型、字級、陰影、亮度都已調妥);
> 若你已有自己的 exult.cfg,則**完全不會被動到**。想還原成預設調校,
> 把這個檔案刪掉再啟動一次即可。

> 註:未來若拿到新版的 Exult.app,直接覆蓋舊的即可——第一次啟動會自動更新
> 中文化資料,你的遊戲檔與存檔都不會被動到。

### 常見問題與排除 (Troubleshooting)

* **Q: Exult.app 打不開,說「無法檢查惡意軟體 / 來自未識別的開發者」?**
  A: 見第一步的提示。用終端機指令解除隔離
     `xattr -dr com.apple.quarantine /Applications/Exult.app`,
     或到 系統設定 → 隱私權與安全性 → 「安全性」區按「仍要打開」。
     這只是因為沒有付費簽章,不是病毒。

* **Q: 「自動搜尋遊戲檔」找不到我的遊戲?**
  A: Spotlight 可能沒有索引到遊戲資料夾。請改用「打開 STATIC 資料夾」手動複製:
     到你安裝《創世紀 7:黑門》的地方(GOG 安裝資料夾),找到 **`STATIC`** 資料夾,
     把裡面**所有檔案**複製進打開的視窗裡。

* **Q: 啟動後選單裡看不到遊戲,或進去報錯找不到素材?**
  A: 請確認 `~/Library/Application Support/Exult/blackgate/STATIC/` 裡面
     有原版遊戲的檔案(重點檢查有沒有 `INITGAME.DAT`)。

* **Q: 遊戲打開還是英文的,或者沒有聲音?**
  A: 中文化檔案會在第一次啟動時自動放到 `blackgate/patch/` 裡。
     請**不要**去覆蓋或刪除裡面的 `usecode`、`chinese.ttf`。
     只要 patch 就位,遊戲就會強制讀取這些中文化資源!

* **Q: 不喜歡現在的中文字型、文字大小、顏色等等?**
  A: 可在 `exult.cfg` 的 `<video>` → `<chinese>` 區塊調整字型路徑、字級、行距、顏色等。
     話說關於字型,礙於版權,整合版裡放的是「思源宋體」,但我最推薦的是「微軟新細明」,
     可以自己從 Windows 系統中弄到~字級可改成 15。

* **Q: 我也有《蛇島 Serpent Isle》,可以玩嗎?**
  A: 引擎支援!把蛇島的 `STATIC` 內容放進
     `~/Library/Application Support/Exult/serpentisle/STATIC/` 即可,
     但目前中文化內容以《黑門》為主。

* **Q: 我是 Intel(非 M 系列)的 Mac,可以玩嗎?**
  A: 本 App 為 Apple Silicon (arm64) 版本。Intel 機型需自行從原始碼編譯
     (見專案 README.md 說明),或使用其他平台版本。
